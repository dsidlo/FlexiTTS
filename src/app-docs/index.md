# FlexiTTS Help

Welcome to FlexiTTS, an audiobook production app for turning story chapters
into per-character narration.

## Getting around

- The main window lists the chapter's dialog lines. Each line is a
  **DialogBar**: a colored header (character name, line number, render
  button) that expands to show the line's text and attributes.
- The **🎭 Characters** button opens the Characters dialog (voice samples,
  emotions, dialog effects, post-processing).
- The **Edit Text** button opens the Markdown editor for the chapter source.

## Sections

- **Quick Keys** — every keyboard shortcut and how to customize them.
- **Edit Text** — the Markdown chapter editor.
- **Chapter Dialog** — working with dialog lines, rendering and staleness.
- **Characters Dialog** — character voices, emotions, effects, import/export.

Press `Ctrl+?` anywhere to reopen this help. Close with `Esc` or the ✕.
