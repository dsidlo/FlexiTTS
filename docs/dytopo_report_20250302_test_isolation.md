## Root Cause Analysis

### The Bug (tests/test_sox_effects.py, line 16):
```python
sys.modules['numpy'] = Mock()
```

### Why It Fails:

1. Python's `sys.modules` is a global cache of imported modules
2. `test_sox_effects.py` mutates this cache, replacing `numpy` with a `Mock` object
3. When `test_websocket_stress.py` imports numpy **after** sox_effects runs:
   ```python
   import numpy as np  # Returns the Mock from sys.modules
   ```
4. The `MockTTSService._process_request()` method calls:
   ```python
   audio_data = np.zeros(audio_samples, dtype=np.float32)
   ```
5. `np.zeros()` returns a Mock object instead of a real numpy array
6. `len(audio_data)` raises: `TypeError: object of type 'Mock' has no len()`

### Evidence:
```

Error: Server error: object of type 'Mock' has no len()
```

```python
@patch('chapter_xml_to_audio.np')

    """Test silence generation."""
    mock_np.zeros.return_value = [0.0] * 24000
```

### Option 2: Cleanup Fixture

